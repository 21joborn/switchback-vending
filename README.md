# Switchback Vending LLC — Website

Customer-facing site for Switchback Vending: free machine placement, custom inventory, and full-service restocking.

## Local preview

1. Add your images to `assets/` (see `assets/README.txt`).
2. Open `index.html` in a browser, **or** in Cursor/VS Code use Live Preview / Live Server.

## Contact form

The form emails submissions to `switchbackvending@gmail.com` through [FormSubmit](https://formsubmit.co).

Check that inbox for an email with an **Activate Form** link and click it (look in spam too). After that, inquiries arrive automatically. No email app should open on the visitor’s computer.

## GitHub + GitHub Pages setup

See the step-by-step guide in chat, or follow:

1. Create a GitHub account / repo
2. Push this folder
3. Enable GitHub Pages (Settings → Pages → Deploy from branch `main` / root)
4. Optional: add a custom domain
